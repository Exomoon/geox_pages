Raster Lab 02 Experimental Sandbox Under Development

Sentinel Lab – Satellite & Terrain Analytics

Experimental remote sensing and raster modelling sandbox exploring high-resolution Sentinel-2 Level-2A (10m BOA) and Copernicus DEM GLO-30. Includes 5 analytical modules: vegetation phenology, wetland dynamics, wildfire burn severity, terrain topography, and AST band algebra. Active R&D.

Sensor & DEM Sentinel-2 + GLO-30
Resolution 10m BOA / 30m DEM
Experiments 5 Modules (NDVI–AST)
Processing Float32 Cloud-Masked

Expertise

Capabilities

Technical focus areas across spatial analysis, automated pipelines and digital interfaces.

// 01

FME Architecture & Spatial ETL

Advanced data transformation workflows in FME Desktop and automated orchestration with FME Flow / Server. Batch pipelines, CAD/BIM-to-GIS and schema normalisation.

// 02

Spatial Databases & PostGIS

High-performance spatial modelling in PostgreSQL/PostGIS, SpatiaLite and DuckDB Spatial. R-Tree/GiST indexing, spatial SQL views and high-throughput analytical queries.

// 03

QGIS & Python Automation

Custom PyQGIS plugin development, automated cartographic batch processing and headless Python geoprocessing integrated into production pipelines.

// 04

Earth Observation & Raster Engines

Applied remote sensing using Copernicus Sentinel-2 MSI and DEM rasters. Float32 band algebra, atmospheric correction (BOA), and cloud masking using GDAL, Rasterio, NumPy and SciPy.

// 05

Multimodal Routing & Isochrones

Multimodal network analysis, travel-time catchment modeling, accessibility isochrones and transit scheduling powered by OpenTripPlanner and GTFS data.

// 06

Interactive Mapping & Web-GIS

Ultra-responsive client-side GIS renderers using MapLibre GL, Leaflet, vector tiles and the custom Nordic Slate design system engineered for low latency.

// 07

Geospatial Solution Architecture

End-to-end spatial infrastructure design: from raw sensor ingestion through automated validation pipelines, spatial databases, and production-grade client interfaces.

// 08

APIs & Service Integrations

Robust services bridging national public registries, spatial databases, WMS/WFS/OGC APIs and responsive client-side geospatial web applications.

// 09

Public Sector Open Data

Structuring, validating and enriching official national datasets (SCB, Lantmäteriet, MSB, Valmyndigheten) into dependable decision-support tools.
