SeaLevelRize — Coastal Landscape Evolution Engine

Flooding a modern digital elevation model (DEM) with historical sea level changes produces misleading paleogeographies. SeaLevelRize reconstructs prehistoric coastlines by coupling regional sea-level curves with tectonic land movement, erosion, and sedimentation.

Scientific Principles & Model Formulation

How morphodynamic processes and relative sea level changes are mathematically reconstructed backwards in time.

Backwards Landscape Evolution Equation

To determine ancient ground elevation at a given age t (years Before Present, 1950), the cumulative geological effects that occurred between time t and today must be inverted:

Zpaleo = Zpresent − U + E − D

Where:

  • Zpaleo: Reconstructed ancient land/bathymetric height in meters.
  • Zpresent: Present-day elevation (GEBCO 2020 datum).
  • U: Cumulative vertical land motion (+ uplift lowers paleo-surface, − subsidence raises paleo-surface).
  • E: Cumulative post-depositional erosion (+ material eroded restores missing paleo-mass).
  • D: Cumulative sediment deposition (+ deposited sediment is stripped away).

Height margin relative to sea level is computed as:
Margin = Zpaleo − S(t), where S(t) is ancient sea surface height.

True Hydrological Connectivity

A cell with negative elevation margin is not necessarily ocean. If it lies in an inland basin cut off by a sill from the open sea, it forms an enclosed sink depression rather than open ocean. SeaLevelRize tracks contiguous 4-way topological connectivity originating from real ocean boundary seeds, preventing artificial inland flooding until a physical sill breach occurs.

Reference Frame Conventions

Relative Mode: When regional RSL curves already include Glacial Isostatic Adjustment (GIA) and subsidence, additional land motion is locked to avoid double-counting.

Separate Mode: Global eustatic sea-level curves paired with explicit, spatially differentiated vertical tectonic fields and GIA displacement models.

Data Provenance

• Elevation: GEBCO 2020 Grid (interpolated to 600m EPSG:3035).
• Sea Level Curves: Lambeck et al., regional Aegean benchmarks.
• Scope: Aegean Basin demo serves as a methodology proof of concept; Doggerland and North Sea expansions planned.

Key Paleogeographic Epochs

22 000 BP · Glacial Maximum

Exposed Continental Shelf

Sea levels dropped ~120m below present. Cycladic island complexes merged into vast contiguous land bridges, severely constraining water exchange through Mediterranean straits.
11 700 BP · Early Holocene

Rapid Marine Transgression

Deglaciation triggered rapid sea-level rise. Marine sills were breached, transforming inland closed depressions into salt-water gulfs and isolating island archipelagos.
0 BP · Present Day Reference

Modern Baseline & Validation

The 1950 calibration baseline where cumulative process offsets equal zero. Used to cross-validate reconstructed DEM grids against modern geodetic benchmarks.

Architecture & Python Pipeline

A modular engine supporting command-line execution, unit-tested models, QGIS visualization, and high-performance Web Mercator exports.

Pipeline Components

  • palaeocoast/model.py: Core scientific model, backward elevation solver, and topological ocean seed flood algorithm.
  • palaeocoast/run.py: Batch execution runner exporting multi-temporal GeoTIFF frames, GeoJSON coastlines, and summary metrics.
  • palaeocoast/web_export.py: Reprojects and warps EPSG:3035 grids to EPSG:3857 Web Mercator for crisp web tiles.
  • palaeocoast/web_server.py: Local HTTP server with JSON caching API for on-the-fly process toggling and cell inspection.
  • palaeocoast/qgis_viewer.py: Standalone PyQGIS timeline slider script for professional cartographers.
